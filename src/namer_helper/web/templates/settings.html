Einstellungen

StashDB Fingerprint-Suche

StashDB ist eine Community-Datenbank für Szenen. Mit einem API-Schlüssel können Dateien über ihre phash/oshash-Fingerprints gefunden werden — ohne den Dateinamen zu verwenden. Der Schlüssel wird lokal in /etc/namer-helper/ai_config.json gespeichert (nur root lesbar).

Unter stashdb.org → Profil → API-Schlüssel zu finden. Ohne Schlüssel funktionieren nur öffentliche (nicht-authentifizierte) Abfragen.

ThePornDB Gegencheck

Token wird automatisch aus namer.cfg gelesen (porndb_token) — kein separates Eintippen nötig.

ThePornDB wird als Gegencheck genutzt: läuft erst nach StashDB und Ollama, bestätigt oder widerspricht deren Ergebnis. Endpoint: https://theporndb.net/graphql (Stash-Box GraphQL).

Ollama Dateinamen-Analyse

Ollama analysiert den Dateinamen lokal und schlägt bereinigte Suchtitel vor — hilfreich wenn Dateinamen viele Tags, Hashtags oder technische Informationen enthalten.

{% if ollama_models_error %} Modelle konnten nicht geladen werden: {{ ollama_models_error }} {% else %} {{ ollama_models|length }} Modell(e) gefunden. {% endif %}

Wähle ein installiertes Textmodell für die Dateinamen-Analyse. Embedding-Modelle wie all-minilm sind für die semantische Suche gedacht.

Pre-Check Verzeichnis

Dateien die hier abgelegt werden können vor der Namer-Verarbeitung geprüft und bereinigt werden. Namer greift auf dieses Verzeichnis nicht direkt zu — erst nach "→ Watch/" startet die Verarbeitung.

📦 Aussortiert-Ordner

Aussortierte Dateien werden hierhin verschoben (nie gelöscht). Leer lassen = neben pre-check/failed auf der lokalen Disk. Auf eine NAS zeigen lassen (z.B. /mnt/nas/aussortiert), damit die kleine Container-Disk nicht vollläuft.
