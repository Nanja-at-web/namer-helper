Proxmox SSH-Integration

namer-helper läuft im LXC-Container und kann NFS nicht direkt mounten. Mit einer SSH-Verbindung zum Proxmox-Host werden die Mounts dort eingerichtet und per Bind-Mount in den Container eingebunden.

SSH-Verbindung zum Proxmox-Host

SSH-Schlüssel (einmalig einrichten)

Diesen öffentlichen Schlüssel einmalig auf proxbox hinterlegen, damit namer-helper sich ohne Passwort verbinden kann.

{{ pubkey if pubkey else "Kein Schlüssel vorhanden — wird beim ersten Start generiert." }}
{% if pubkey %}

Auf proxbox ausführen:

echo '{{ pubkey }}' >> /root/.ssh/authorized_keys

Oder: ssh-copy-id -i /etc/namer-helper/.ssh/id_ed25519.pub root@{{ cfg.host if cfg.host else "<proxbox-ip>" }} (von einem anderen Rechner ausführen)

{% endif %}

NFS-Mounts über Proxmox-Host einrichten

Für jeden NFS-Mount aus der Mounts-Konfiguration kann namer-helper den Mount auf dem Proxmox-Host einrichten und per Bind-Mount in den Container einbinden. Danach ist ein Container-Neustart erforderlich.

{% if nfs_mounts %}
{% for m in nfs_mounts %}
{{ m.label if m.label else "NFS" }}
{{ m.host }}:{{ m.share }} → {{ m.target }}
{% endfor %}
{% else %}
Keine NFS-Mounts konfiguriert. Zuerst unter Mounts einen NFS-Eintrag anlegen.
{% endif %}

Container neu starten

Nach dem Einrichten eines Host-Mounts muss der LXC-Container neu gestartet werden, damit der Bind-Mount aktiv wird. Das WebUI ist kurz nicht erreichbar.
